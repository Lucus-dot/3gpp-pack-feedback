# 3GPP 提案分析技能包 · 反馈区

**这里只收意见，不放代码。**

技能包是付费分发的，源码不在这里，也不会放在这里。这个仓库存在的唯一目的，是让用 GitHub 的人有个地方报问题、提需求。

## 报问题之前，先跑一下这个

在技能包目录下执行：

```bash
python scripts/doctor.py --work-dir <你这次的 work-dir>
```

它会把版本、Python、系统、授权状态（只显示编号后 6 位）、关键文件完整性、以及这次运行报过的所有 `E-` / `W-` 错误码一次性打出来。

**整段复制，贴进下面的模板。** 比你手打十句话都有用，能省掉一半来回。它只读、不联网、只用标准库，不需要装任何东西。

## 提交

- [报个问题](https://github.com/Lucus-dot/3gpp-pack-feedback/issues/new?template=bug.yml) —— 跑不通、结果不对、报错了
- [提个需求](https://github.com/Lucus-dot/3gpp-pack-feedback/issues/new?template=idea.yml) —— 想要某个能力、觉得某步太绕

不会用 GitHub 也没关系，在购买渠道私信我即可，贴同样的内容。

## 关于回复时间

问题会看，也会修，但**不承诺具体时间**。影响跑通的问题优先；功能建议按性价比排期。

## 请不要在这里贴

- 完整的 TDoc 原文、会议材料（版权与保密问题）
- 授权编号的完整值（只报后 6 位就够定位是哪一批）
- 公司内部的项目名、客户名
